# 手羽屋日報アプリ 参照データ

## 実装済みの機能

- **トップメニュー**（/） - アプリの入口ページ
- **営業後日報**（/report） - 7ステップ形式で営業終了後の報告を入力
- **中間報告**（/interim） - 営業中の途中経過を報告
- **管理者ページ**（/admin）
  - 月次集計（月ごとの売上まとめ）
  - 日報一覧（過去の日報を確認）
  - 日報削除機能
- **レシートOCR自動入力機能** - レシート写真から自動で数字を読み取り
- **レジ差異金額入力** - レジのお金の過不足を記録
- **2回連続マイナス補填アラート** - レジが2回続けてマイナスのとき警告
- **持ち帰り金額集計** - テイクアウト売上の集計
- **タスク管理**（/tasks） - スタッフ向けタスク管理機能
- **月間売上目標vs実績ダッシュボード** - 目標と実績の比較表示
