# 会計ソフトに取り込めるファイルの決まり（2026-09-24 調べ）

お試し版（/keiri/demo）と本物（/keiri）から書き出すファイルが、
相手の会計ソフトに**本当に取り込めるか**を確かめた記録です。

**調べ方について（正直に書いておきます）**：この実行環境からは外のサイトを直接
開けない設定になっていたため（弥生・freee・マネーフォワードの公式サポートは
いずれも「接続できません」で止まりました）、**検索結果に出てきた公式サポートページの
要約**を根拠にしています。下の「出典」に、要約のもとになった公式ページのURLを
そのまま残してあります。**最終の突き合わせは、実際に1回取り込んでみるのが確実です。**

---

## 1. 弥生会計 / やよいの青色申告（いちばん厳しい）

| 決まり | 内容 |
|---|---|
| 列の数 | **25個ちょうど**（27個でも可）。使わない列も空のまま置いてカンマの数を合わせる |
| 見出し行 | **付けない**。1行目からいきなり仕訳 |
| 文字コード | **Shift-JIS**（UTF-8 だと文字化け・取り込みエラー） |
| 日付 | `2026/09/01`（`2026-09-01` は不可） |
| 金額 | カンマ区切りにしない（`12000`） |
| 1列目 識別フラグ | 1行で完結する仕訳なら **`2000`**（必須） |
| 20列目 タイプ | **`0`**（仕訳日記帳での入力形式・必須） |
| 25列目 調整 | **`no`**（必須） |
| 取り込み画面 | 列を選び直す画面は**無い**。並びが違うと弾かれる |

列の並び（左から）：
識別フラグ / 伝票No / 決算 / 取引日付 / 借方勘定科目 / 借方補助科目 / 借方部門 /
借方税区分 / 借方金額 / 借方税金額 / 貸方勘定科目 / 貸方補助科目 / 貸方部門 /
貸方税区分 / 貸方金額 / 貸方税金額 / 摘要 / 番号 / 期日 / タイプ / 生成元 /
仕訳メモ / 付箋1 / 付箋2 / 調整

出典（2026-09-24 確認）：
- https://support.yayoi-kk.co.jp/subcontents.html?page_id=18545 （仕訳データの項目と記述形式）
- https://support.yayoi-kk.co.jp/subcontents.html?page_id=29611 （インポートデータの記述形式）
- https://support.yayoi-kk.co.jp/faq_Subcontents.html?page_id=23508 （CSVファイル取込のファイル形式・文字コード）

## 2. マネーフォワード クラウド会計

| 決まり | 内容 |
|---|---|
| 列の数 | 仕訳帳インポートは **27列** |
| 見出し行 | **付ける**（取り込み画面で列を選ぶときの目印になる） |
| 文字コード | Windows は **Shift-JIS**、Mac は **UTF-8** |
| 日付 | `2026/09/01`（yyyy/MM/dd） |
| 必須 | 取引日・勘定科目・金額 |
| 取り込み画面 | 「この列は何ですか」を**選び直せる** |

出典（2026-09-24 確認）：
- https://biz.moneyforward.com/support/tax-return/guide/import-books/ib01.html （「仕訳帳」をインポートする）
- https://biz.moneyforward.com/support/account/guide/books2/bo01.html （「仕訳帳」画面の使い方・文字コード）

## 3. freee 会計

| 決まり | 内容 |
|---|---|
| 必須の項目 | 発生日 / 伝票番号 / 借方勘定科目 / 貸方勘定科目 / 貸借金額 / 貸借税額 |
| 見出し行 | 付ける（取り込み後に列を選ぶ） |
| 取り込み画面 | 「この列は何ですか」を**選び直せる**ので、並びは自由 |

出典（2026-09-24 確認）：

## 突き合わせの結果（いま出しているファイルとの差）

| 相手 | いままで | 判定 |
|---|---|---|
| マネーフォワード | 27列・見出しあり・`2026/09/01`・UTF-8(BOM)とShift-JISの2本 | **合っている。直しなし** |
| freee | 上のマネーフォワード用をそのまま使える（列を選び直せるため）。取引日→発生日、取引No→伝票番号 | **合っている。画面に一言だけ足した** |
| 弥生会計 | **出していなかった**（Excel向け6列＝見出しあり・UTF-8 しかなく、弥生には弾かれる） | **今回 追加**（`lib/keiri/yayoi.ts`） |

### 今回直したこと
- `lib/keiri/yayoi.ts` を新しく作り、弥生の25列の形で書き出せるようにした。
- 本物（/keiri）とお試し版（/keiri/demo）の両方に「弥生用CSV」のボタンを足した。
- どのボタンがどの会計ソフト向けかを、ボタンのそばに1行ずつ書いた。
- 摘要に絵文字などが混ざっていても弥生が壊れないよう、Shift-JIS に無い文字は落とす。

### 直していないこと（意図的）
- 税区分・税額は**空のまま**（このアプリは税務判断をしない。CLAUDE.md 5-2）。
  弥生は税金額の列だけ `0` を入れてある（空だと弾かれる版があるため）。

## 書き出したファイルを1列ずつ確かめた記録（2026-09-24）

サンプル3行（売上／食材の仕入れ（摘要にカンマと絵文字入り）／外注費）で書き出した弥生用CSV：

```
2000,1,,2026/09/01,現金,,,,42500,0,売上高,,,,42500,0,売上 ながやま鷹尾,,,0,,,,,no
2000,2,,2026/09/01,仕入高,,,,12340,0,現金,,,,12340,0,"食材, 業務用スーパー",,,0,,,,,no
2000,3,,2026/09/30,外注費（Alpha）,,,,4250,0,未払金,,,,4250,0,Alpha 業務委託料,,,0,,,,,no
```

| # | 列 | 中身 | 判定 |
|---|---|---|---|
| 1 | 識別フラグ | `2000` | OK（1行で完結する仕訳） |
| 2 | 伝票No | `1`（1から順） | OK |
| 3 | 決算 | 空 | OK |
| 4 | 取引日付 | `2026/09/01` | OK（ハイフンではない） |
| 5 | 借方勘定科目 | `現金` | OK |
| 6-8 | 借方補助科目/部門/税区分 | 空 | OK（税務判断をしない） |
| 9 | 借方金額 | `42500` | OK（カンマ区切りにしない） |
| 10 | 借方税金額 | `0` | OK |
| 11 | 貸方勘定科目 | `売上高` | OK |
| 12-14 | 貸方補助科目/部門/税区分 | 空 | OK |
| 15 | 貸方金額 | `42500` | OK |
| 16 | 貸方税金額 | `0` | OK |
| 17 | 摘要 | `売上 ながやま鷹尾` | OK |
| 18-19 | 番号/期日 | 空 | OK |
| 20 | タイプ | `0` | OK（必須） |
| 21-24 | 生成元/仕訳メモ/付箋1/付箋2 | 空 | OK |
| 25 | 調整 | `no` | OK（必須） |

- 列の数：**25個ちょうど**
- 見出し行：**なし**
- 摘要のカンマ：`"食材, 業務用スーパー"` と引用符でくくられ、行が割れていない
- 摘要の絵文字（🍗）：**落ちている**（Shift-JIS に無いため。残すと行が丸ごと文字化けする）
- Shift-JIS に直したあと：**262バイト・先頭のBOMなし**・読み戻して日本語が元どおり
