## 2. 商品と価格（じゅんの「はい／いいえ」1つで決められる案）

## 3. 申込から使い始めまでの流れ（人が一切出てこない）

1. 事例ページ `/keiri/case`（日本語のみ）：手羽屋の実数・画面の写真（自分のアプリなので権利問題なし）・「申し込む」ボタン
2. ボタン → Stripe Payment Link（月額）。名前・メール・カードは Stripe の画面で本人が入力
3. 支払い完了 → Stripe が `/api/keiri/stripe-webhook` に通知（署名検証：LINE の Webhook と同じ考え方）
4. Webhook が **`keiri_tenants`** に1行作る（店名＝Stripe の顧客名、テンプレ＝`generic`、管理者パスワード＝自動生成）
5. Stripe の「支払い完了メール」に **初回ログインURL** を載せる（Stripe 側のメール文面に固定文で書く。自前でメールは送らない＝外に出る行動を作らない）
6. お客さんが `/keiri/welcome` で店名・期首日・期首残高（3項目）を入れる → その日から日報を打てば数字が出る
7. 困ったら → `/feedback`（意見箱・Claude 自動回答）。解約 → Stripe 顧客ポータル
