# 経理パッケージ：申し込みが入ったあと、本当に使い始められるか（2026-09-18 実測）

## なぜ調べたか

いま最優先は「最初の1件を取ること」。
じゅんが知り合いの店主に紹介の URL を送る手前まで来ている。
そこで、**お客さんがお金を払ったあと、人の手を借りずに使い始められるか**を
本番（公開しているサイト）に外から触って確かめた。
お金だけ払えて使い始められない、がいちばん困る失敗なので、送る前に確かめる。

## 申し込みは4つがつながって初めて成立する

| | つながっているもの | 何が無いとどうなるか |
|---|---|---|
| ① | 申し込みボタン（支払いページへのリンク） | そもそも申し込めない |
| ② | 支払いが終わったという**通知の受け口**（合言葉） | 払ったのに、こちらに何も届かない |
| ③ | お店1軒ぶんの行を作る**置き場**（`keiri_tenants`） | 申し込んだお店を作れない |
| ④ | 初回設定を書き込む**置き場**（`keiri_settings`） | 店名・数え始めの日を保存できない |

さらに Stripe（カード払いの仕組み）の画面側で、人が1回だけ設定する項目が2つある。
これはこちらのプログラムからは見えないので、目で確かめるしかない。

- 支払いのあとの**戻り先**：`https://tebaya-report.vercel.app/keiri/welcome?session={CHECKOUT_SESSION_ID}`
- 支払いが終わったことの**知らせ先**：`https://tebaya-report.vercel.app/api/keiri/signup-webhook`（出来事は `checkout.session.completed`）

## 実測した結果（2026-09-18・本番）

| 調べたこと | どうやって | 結果 |
|---|---|---|
| 申し込みボタン | `/keiri/case` を開いた | **出ている**（月額3,000円・税込／支払いページへ飛ぶ） |
| 通知の受け口の合言葉 | `GET /api/keiri/signup-webhook` | `{"secret":"未設定"}` ＝ **未設定** |
| 申し込みのあとの初回設定 | `POST /api/keiri/welcome`（存在しない合言葉で1回） | **500**（お店を引くところで失敗）。置き場（表）がまだ無い可能性が高い |

つまり、いまの本番は **①だけつながっていて、②以降が切れている**。
このまま URL を送ってお客さんが払うと、
「このリンクは使えません」と出て、そこで止まる。

## そこで作ったもの（この下書きの中身）

**`GET /api/keiri/diagnose`** … 上の①〜④を1回で確かめる診断。
返ってくるのは「つながっているか（ready）」と「残っているやること（todo）」の一覧。

- 合言葉・鍵の**値そのものは絶対に返さない**（設定済み／未設定だけ）。CLAUDE.md 4-10 と同じ扱い。
- **読むだけ。1行も書き込まない。**
- 手羽屋の日報・シフト・LINE には一切触れていない。
- 判定の中身は `lib/keiri/signupReadiness.ts`（通信をしない純粋な計算）。
  入り口の `app/api/keiri/diagnose/route.ts` は「調べる → 渡す → 返す」だけ。
  `tests/keiriSignupReadiness.test.ts` で固定（6件）。

これがあると、**送る前に毎回1回開くだけで、受け皿が生きているか確かめられる。**

## 残っているやること（じゅんの画面操作・どれも一度きり）

1. **Supabase**（データの倉庫）の SQL Editor で `supabase/migrations/keiri_tenants.sql` と
   `supabase/migrations/keiri_settings_and_payments.sql` を貼って実行する。
   既存の表には触れず、何度実行しても安全。
2. **Stripe** で知らせ先（Webhook）を上の URL に登録し、出てきた合言葉を
   **Vercel**（サイトが動く場所）の環境変数 `KEIRI_SIGNUP_WEBHOOK_SECRET` に入れる。
3. **Stripe** の支払いリンクの「支払い後の戻り先」を上の URL にする。

3つとも、画面の案内はチャットで出す。
終わったら `/api/keiri/diagnose` を開いて `ready: true` になっていることを確かめる。
